# XiaoYun — a little love website

This is a self-contained static website. To publish it as a public link:

1. Open [Netlify Drop](https://app.netlify.com/drop).
2. Drag this entire `xiaoyun` folder onto the page.
3. Netlify will immediately give you a public `netlify.app` URL that you can share.

The site does not need a build command or server. For local preview, open `index.html` directly or run:

```text
python -m http.server 4173
```

Then visit `http://localhost:4173`.
